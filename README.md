# Runner Shortcut Hub

Runner Shortcut Hub is a categorized shortcut dashboard that replaces the Chrome new tab page.

## Project folders

- `outputs/chrome-new-tab-dashboard-extension`: unpacked Chrome extension
- `outputs/chrome-web-store-submission`: Chrome Web Store materials
- `docs/superpowers/specs`: feature design specifications

## Load locally

1. Open `chrome://extensions` in Chrome.
2. Enable Developer mode.
3. Choose **Load unpacked**.
4. Select `outputs/chrome-new-tab-dashboard-extension`.
