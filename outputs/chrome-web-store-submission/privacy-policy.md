# Privacy Policy for Runner Shortcut Hub

Last updated: August 6, 2026

Runner Shortcut Hub is a Chrome extension that replaces the new tab page with a customizable shortcut dashboard. Its single purpose is to help users organize and open websites from a personalized Chrome new tab page.

## Data Stored Locally

Runner Shortcut Hub stores the following information in Chrome's local extension storage:

- Shortcut titles, URLs, colors, icons, order, and local usage counts
- Category names, icons, order, and local usage counts
- Imported bookmark titles and URLs
- Search history and custom search-engine settings
- Language, appearance, layout, wallpaper, and preset settings
- Optional user-uploaded category icons and background images

This information is used only to display and restore the user's dashboard. It is not sent to the developer or to a developer-operated server.

## Bookmark Access

The extension reads Chrome bookmarks only when the user starts the bookmark import feature. Bookmark folder names, bookmark titles, and bookmark URLs selected for import are copied into the local dashboard. Bookmark data is not uploaded, sold, shared, or used for advertising.

## Search and External Websites

When the user submits a search or opens a shortcut, Chrome navigates to the selected search engine or website. Those external sites may process the query or URL under their own privacy policies. Runner Shortcut Hub does not proxy, inspect, or transmit that navigation to the developer.

## Data Collection and Sharing

Runner Shortcut Hub does not collect, sell, share, or transmit user data to the developer. It does not use analytics, advertising SDKs, tracking pixels, or remotely hosted executable code.

The extension's use of information received from Chrome APIs complies with the Chrome Web Store User Data Policy, including its Limited Use requirements. Data is used only to provide the user-facing dashboard features, is not transferred for advertising or credit-related purposes, and is not made available for human review.

## Permissions

- `bookmarks`: reads bookmark folders and entries only for a user-initiated import into dashboard categories.
- `favicon`: displays website icons for user-saved shortcut URLs through Chrome's favicon API.
- `management`: lets the user disable Runner Shortcut Hub itself from its own interface to restore Chrome's original new tab page. The extension does not manage other extensions.
- `storage`: saves dashboard data and preferences locally in Chrome.
- `unlimitedStorage`: allows optional user-uploaded icons, wallpapers, and appearance presets to remain available locally without a small storage quota interrupting those features.

## Data Retention and Deletion

Data remains in local Chrome extension storage until the user deletes it or uninstalls the extension. Users can delete shortcuts and categories, clear search history, remove custom backgrounds, or reset appearance settings from the extension interface. Uninstalling the extension removes its locally stored data according to Chrome's storage behavior.
