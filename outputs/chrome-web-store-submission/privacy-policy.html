Privacy Policy for Runner Shortcut Hub

Last updated: July 5, 2026

Runner Shortcut Hub is a Chrome extension that replaces the new tab page with a customizable shortcut dashboard.

Data Stored by the Extension

The extension stores shortcut titles, shortcut URLs, shortcut colors, category names, optional category icon images, optional custom background images, search history entries, selected language, selected appearance, and selected view mode locally in Chrome storage. This information is used only to display and restore the user's new tab dashboard, uploaded local icon/background images, and optional search history.

Data Collection and Sharing

Runner Shortcut Hub does not collect, sell, share, or transmit user data to the developer. The extension does not use analytics, advertising SDKs, tracking pixels, or remote code.

Permissions

The extension uses the storage permission to save the user's dashboard settings locally. The extension uses the favicon permission to display website icons for user-saved shortcut URLs through Chrome's favicon API.

Data Deletion

Users can delete shortcuts and categories inside the extension interface. Users can also remove all locally stored extension data by uninstalling the extension from Chrome.

Contact

For privacy questions, use the developer contact email listed on the Chrome Web Store page.
