**Detailed description**

Runner Shortcut Hub 将 Chrome 新标签页替换为一个可分类、可定制的快捷方式控制台。你可以把常用网站、搜索入口和工作分类集中到一个页面，并在浏览器本地保存所有设置。

主要功能：

- 创建、编辑和排序网站快捷方式与分类
- 从 Chrome 书签栏按文件夹导入网站
- 切换 Google、Bing、DuckDuckGo 等搜索引擎，并添加自定义搜索引擎
- 选择手动顺序或按本地使用频次排序快捷方式
- 简体中文与 English 即时切换
- 多种界面主题、主题色、壁纸、透明度、模糊和圆角设置
- 保存、导入、导出和恢复外观预设
- 一键停用扩展并恢复 Chrome 原版新标签页
- 快捷方式、书签导入结果、搜索历史和外观设置均保存在 Chrome 本地

Runner Shortcut Hub does not use analytics, advertising SDKs, tracking pixels, or remotely hosted executable code. It does not send dashboard data to the developer.

Runner Shortcut Hub replaces Chrome's New Tab page with a categorized, customizable shortcut command center.

Key features:

- Create, edit and reorder website shortcuts and categories
- Import bookmark-bar folders directly into dashboard categories
- Switch between built-in search engines or add custom engines
- Keep manual shortcut order or sort by locally recorded usage frequency
- Switch instantly between Simplified Chinese and English
- Customize themes, colors, wallpapers, opacity, blur and corner radii
- Save, import, export and restore appearance presets
- Disable the extension from its interface to restore Chrome's original New Tab page
- Keep shortcuts, imported bookmark data, search history and appearance settings in local Chrome storage

## Single purpose

Runner Shortcut Hub replaces Chrome's New Tab page with a local, customizable dashboard for organizing, searching and opening websites.

## Permission justifications

- `bookmarks`: Reads bookmark folders and entries only when the user starts a bookmark import, then copies the selected titles and URLs into local dashboard categories.
- `favicon`: Displays icons for user-saved shortcut URLs through Chrome's built-in favicon API.
- `management`: Allows the user to disable Runner Shortcut Hub itself from the dashboard and restore Chrome's original New Tab page. It does not manage other extensions.
- `storage`: Saves shortcuts, categories, search settings, appearance settings and preferences locally in Chrome.
- `unlimitedStorage`: Keeps optional user-uploaded icons, wallpapers and appearance presets available locally without a small storage quota interrupting those features.
