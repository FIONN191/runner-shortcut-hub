# Runner Shortcut Hub 扩展开关、书签导入与性能优化设计

## 背景

Runner Shortcut Hub 当前通过 `chrome_url_overrides.newtab` 接管 Chrome 新标签页。现有“Chrome 原版”按钮只尝试导航到 `chrome://new-tab-page/`，失败后切换到插件内部的仿 Chrome 页面，并不能真正恢复 Chrome 原生新标签页。

插件当前还叠加了整页入场动画、背景模糊和多层 `backdrop-filter`。这些效果在包含大量快捷方式或自定义壁纸时会增加首屏合成与滚动成本。用户还希望把 Chrome 书签栏中已经整理好的文件夹一次导入为快捷中心分类，并避免单个分类出现实际容量上限。

## 目标

1. 提供一个明确的“关闭插件”按钮，禁用扩展后立即恢复真正的 Chrome 原生新标签页。
2. 直接读取 Chrome 书签栏，将一级文件夹映射为快捷中心分类，并递归导入所有子文件夹中的网站。
3. 全局跳过重复网址，不覆盖现有快捷方式。
4. 导入过程事务化，失败时不破坏已有分类、网站、排序、外观或预设数据。
5. 移除非必要的整页动画和高成本常驻模糊，使新标签页打开、滚动和交互更流畅。
6. 不限制单个分类的网站数量，并解除 Chrome Storage 的默认容量配额限制。
7. 所有新增界面和反馈支持简体中文与 English。

## 非目标与平台限制

- 不修改、移动、重命名或删除 Chrome 书签。
- 不在导入后持续同步 Chrome 书签；本功能是用户主动触发的一次性导入。
- 不把书签导入外观预设或完整数据备份之外的新存储域。
- 不删除自定义壁纸上传功能。
- Chrome 在扩展接管新标签页时显示的扩展归属/“Customize Chrome”底栏不属于扩展页面 DOM，插件无法通过 HTML 或 CSS 隐藏。真正禁用扩展后才会退出扩展新标签页。
- 扩展禁用后自身代码不再运行，因此不能在 Chrome 原生新标签页提供重新开启按钮。用户需要进入 `chrome://extensions` 重新启用。

## 权限

在 `manifest.json` 中增加：

- `bookmarks`：读取 Chrome 书签树。代码只调用读取 API。
- `management`：仅用于对 `chrome.runtime.id` 调用 `chrome.management.setEnabled(id, false)`。
- `unlimitedStorage`：移除 Chrome Storage 默认容量配额，避免大量快捷方式、图标和外观数据形成隐性容量上限。

Chrome 可能在安装或更新时显示书签与扩展管理权限提示。界面中的说明必须明确：书签只读；关闭操作只作用于 Runner Shortcut Hub 自身。

## 界面设计

### 关闭扩展

- 将系统面板中的“Chrome 原版 / Chrome Original”替换为“关闭插件 / Disable Extension”。
- 点击后复用现有确认模态框。
- 中文确认文案说明：关闭后立即恢复 Chrome 原生新标签页；重新开启需进入 `chrome://extensions`。
- 英文模式显示等价完整文案。
- 用户确认后，在点击事件的用户手势链中调用 `chrome.management.setEnabled(chrome.runtime.id, false)`。
- API 失败或扩展由策略管理、不能禁用时，保持当前页面和数据不变，并显示本地化错误提示。
- 删除内部仿 Chrome 页面作为“原版主页”回退的入口，避免继续产生误导；已有数据中的 `mode: "classic"` 在迁移时归一化为 Runner 模式。

### 从 Chrome 书签导入

- 在 Customize 面板“完整数据导入与导出”区域新增“从 Chrome 书签导入 / Import from Chrome Bookmarks”按钮。
- 点击后读取书签树并打开导入预览模态框。
- 预览按 Chrome 书签栏中的一级文件夹显示名称、递归网站数和勾选框，默认全部选中。
- 书签栏根目录中未放入文件夹的网站显示为一个“书签栏 / Bookmarks Bar”导入项。
- 模态框提供“取消”和“导入所选”操作，并在为空、无权限或读取失败时显示明确状态。
- 导入结果使用现有反馈模态框或 Toast，显示：新增分类数、导入网站数、重复跳过数、无效跳过数。

## 书签映射规则

1. 只读取 Chrome 书签栏，不导入“其他书签”、移动设备书签或由浏览器提供的其他根目录。
2. 书签栏每个一级文件夹映射为一个快捷中心分类。
3. 一级文件夹内的全部子文件夹递归展开，其网站统一归入对应的一级分类。
4. 同名分类按规范化后的名称匹配并合并，不新建“Imported”副本。
5. 分类和网站顺序遵循 Chrome 书签树中的原始顺序；合并到现有分类时，导入网站追加到当前网站之后。
6. 书签标题为空时使用现有 `inferShortcutTitle(url)` 生成名称。
7. 图标沿用现有 favicon 自动匹配逻辑，不抓取或执行书签页面内容。
8. 只接受 `http:` 和 `https:` 地址。`javascript:`、`data:`、`file:`、`chrome:`、扩展地址和无法解析的网址记为无效并跳过。
9. 去重在整个快捷中心范围执行，而不是只在目标分类内执行。网址比较会移除无意义的尾部斜杠、统一协议和主机大小写，同时保留有意义的路径、查询参数和端口。
10. 同一批导入中重复出现的网址也只导入一次。

## 数据流与事务

书签导入拆分为可独立测试的步骤：

1. `readBookmarksBar()`：调用 `chrome.bookmarks.getTree()` 并定位书签栏节点。
2. `buildBookmarkImportPreview(tree)`：生成一级导入项、递归计数和稳定顺序，不修改应用状态。
3. `normalizeBookmarkUrl(url)`：只返回允许导入的标准化 HTTP(S) 地址和去重键。
4. `buildBookmarkImportCandidate(state, selectedGroups)`：克隆当前状态，合并分类、追加快捷方式并生成统计结果。
5. `commitBookmarkImport(candidate)`：通过现有 Chrome Storage 写入路径一次性保存候选状态。
6. 写入成功后才替换内存中的 `state` 并重新渲染；写入失败时保留原状态。

快捷方式 ID 使用现有 ID 生成规则并检查碰撞。批量导入不会逐条写入 Storage，也不会逐条触发完整页面渲染。

## 性能优化

- 删除顶部、工作区和页脚的整页入场动画及延迟。
- 保留按钮、菜单和卡片的短促状态反馈，但只动画 `opacity`、`transform`、颜色和边框颜色。
- 常驻页面面板不再默认使用多层 `backdrop-filter`；仅在用户明确设置面板模糊且当前主题需要时启用一层模糊。
- 自定义背景继续支持用户设定的模糊值，但背景解码、存储优化和渲染不阻塞主要交互。
- 启动时避免先完整渲染默认数据再完整渲染保存数据；先应用轻量本地外观偏好，再读取持久数据并完成一次主要内容渲染。
- 批量导入结束后只执行一次数据保存和一次完整渲染。
- 保留并加强 `prefers-reduced-motion` 支持。

## 国际化

以下内容必须通过现有统一翻译字典提供中英文：

- 关闭插件按钮、标题、确认说明、失败提示和重新开启说明。
- 书签导入按钮、预览标题、书签栏名称、选择状态、空状态和读取错误。
- 导入统计中的分类、成功、重复和无效数量。
- 新增按钮的 `aria-label`、`title` 与相关输入的辅助文字。

品牌名、书签原始标题和用户分类名称不翻译。

## 错误处理

- Bookmarks API 不可用或权限缺失：不打开空白导入流程，显示“无法读取 Chrome 书签”。
- 未找到书签栏：显示“未找到可导入的书签栏”。
- 没有可导入网站：保留预览，可关闭，不写入存储。
- 未选择导入项：禁用“导入所选”按钮。
- Storage 写入失败：不改变内存状态，显示“导入失败，现有数据未修改”。
- Management API 不可用、当前扩展不可禁用或用户取消 Chrome 原生确认：扩展保持启用并显示失败/取消反馈。
- 所有异步按钮在执行时进入忙碌状态，防止重复提交。

## 测试

### 自动测试

- 从模拟书签树定位书签栏，排除其他书签根目录。
- 一级文件夹映射分类，多层子文件夹递归归入一级分类。
- 根目录网站归入“书签栏”分类。
- 同名分类合并并保持稳定排序。
- 现有状态和同批导入中的全局重复网址均跳过。
- 空标题自动生成，非法协议和无效网址跳过。
- 1000 个以上书签可构建并一次保存，不存在单分类数量截断。
- 写入失败时状态完全回滚。
- 关闭扩展只以 `chrome.runtime.id` 调用 `setEnabled(..., false)`。
- 关闭取消/失败不会导航或改变数据。
- 新增中英文翻译键、ARIA 文案和 manifest 权限存在。
- 性能 CSS 不再包含整页入场动画，减少常驻模糊，同时保留 reduced-motion 规则。

### 手动验收

1. 新标签页首次打开和滚动明显更流畅，无延迟入场动画。
2. 自定义壁纸、主题和已有快捷方式保持可用。
3. 书签预览中的文件夹和递归数量正确。
4. 导入后分类、顺序、标题和网站正确，刷新后仍存在。
5. 重复和无效网站不会写入，并显示准确统计。
6. 包含 1000 个以上网站的分类不会被截断。
7. 点击关闭并确认后，扩展被禁用且新标签页恢复 Chrome 原生界面。
8. 从 `chrome://extensions` 重新启用后，原有 Runner 数据仍然存在。
9. 中文和 English 模式下新增界面不存在混合语言。
10. 控制台无未处理异常。

## 验收标准

- 功能实现与本设计一致，不修改 Chrome 书签内容。
- 书签批量导入和扩展关闭均由明确用户操作触发。
- 导入失败不破坏现有数据。
- 单个分类没有应用层数量上限，存储权限允许大规模数据。
- 真正关闭扩展后恢复 Chrome 原生 New Tab，并明确告知重新开启方式。
- 截图中的 Chrome 浏览器底栏不通过不受支持的 DOM/CSS 技巧隐藏。
- 不删除壁纸上传、分类、快捷方式、排序、搜索、外观预设和完整备份功能。
