# L 形直角装饰线全局开关设计

## 目标

为 Runner Shortcut Hub 增加一个独立的全局外观开关，用于控制界面中的加粗 L 形直角装饰线。该功能不再根据卡片圆角自动判断；默认全局关闭，只有用户主动开启后才显示。

## 界面

- 在 `自定义 -> 尺寸与圆角` 中增加设置开关。
- 中文名称：`L 形直角装饰线`。
- 英文名称：`L-shaped Corner Accents`。
- 使用现有设置开关的尺寸、边框、字体、焦点和悬停样式。
- 修改后立即预览，无需额外保存。

## 行为

- 新增外观字段 `cornerAccentsEnabled`，类型为布尔值，默认值为 `false`。
- 关闭时隐藏品牌区、搜索区、状态区、主工作区、弹窗和网站卡片上的 L 形装饰线。
- 开启时恢复这些区域现有的 L 形装饰线。
- 开关与 `cardRadius` 相互独立：圆角或直角卡片都只服从该开关。
- 删除此前 `has-rounded-cards` 对装饰线显示状态的自动控制。

## 持久化与兼容

- 复用现有 `appearance` 存储结构和保存流程。
- 页面刷新和重新打开 Chrome 后保留用户选择。
- 保存、更新、应用、导入和导出外观预设时包含 `cornerAccentsEnabled`。
- 旧数据或旧预设缺少该字段时迁移为 `false`，避免升级后装饰线突然出现。
- 恢复默认外观时将该字段重置为 `false`，不修改网站、分类或排序数据。

## 实现方式

- JavaScript 根据设置切换 `body.show-corner-accents` 类。
- CSS 默认隐藏受控区域的 `::before` 和 `::after` 角线；仅在 `show-corner-accents` 存在时显示。
- 未知导入字段继续按现有安全规则忽略，不执行导入文件中的任何内容。

## 验收

1. 首次打开和旧版本升级后，所有 L 形装饰线默认关闭。
2. 开启开关后，所有受控区域立即显示装饰线。
3. 关闭开关后，所有受控区域立即隐藏装饰线。
4. 改变卡片圆角不会擅自改变装饰线状态。
5. 刷新页面后状态不变。
6. 外观预设可保存、恢复、导入和导出该状态。
7. 中英文界面的名称和辅助文本完整切换。
8. 恢复默认后开关关闭，网站和分类数据保持不变。
9. 现有搜索、分类、卡片和弹窗交互不受影响。
